# Linear

- **Linear is the tracker for every Hexis-driven project.** Outside Hexis (`~` / `~/.claude`)
  `hooks/tracker-lock.py` denies the Linear and Plane tools until it is retired; Plane stays frozen.
- The operating policy (delegate not assignee, one topic per issue, never delete, the brief is the issue and travels
  inline, one run per sub-issue, milestones as versions) is the skill `hexis-linear`, pushed on the first Linear action
  of a session; full text in `skills/hexis-linear/reference.md`.
